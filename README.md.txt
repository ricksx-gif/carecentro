# CareCentro

Plataforma SaaS para la gestión integral de centros de cuidado de adultos mayores.

## 🎯 Objetivo

Digitalizar y optimizar la administración, control de asistencia, gestión de medicamentos y pagos en centros de cuidado pequeños y medianos (20–60 residentes).
